A clean, responsive UI clone of the Instagram and Facebook login screens built with Flutter. This project demonstrates core layout structures, form handling, basic conditional validation logic using if-else statements, and screen navigation.

Project Features
Dual Interface: Includes both Instagram and Facebook login screen designs.

Input Fields: Customized email/username and password TextField widgets with styled borders, hints, and padding.

Interactive Buttons: Action buttons using ElevatedButton for main login actions and TextButton for secondary actions like "Forgot Password?" and creating new accounts.

Basic Validation: Utilizes if-else condition checks on email and password inputs before triggering action handlers.

Screen Navigation: Smooth transition between screens using Navigator.push.
